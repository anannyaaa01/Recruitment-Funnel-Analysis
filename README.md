# Recruitment-Funnel-Analysis
A business analyst portfolio project analyzing recruitment pipeline 
efficiency across 300 candidates, 6 departments, and 6 sourcing channels. 

Built to answer: where are candidates dropping off, which source produces 
the best hires, and why are candidates rejecting offers?

Tools: SQL · Power BI · Python · Excel
Skills demonstrated: funnel analysis, DAX measures, stakeholder reporting, 
data visualization, business recommendations
